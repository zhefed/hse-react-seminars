# Семинар «Подходы к стилизации» — практические задания

```bash
npm install
npm run dev   # http://localhost:5173
```

Node.js 20.19+ или 22.12+ (требование Vite 8).

На главной странице — список заданий. Каждое открывается отдельной страницей
(`?task=1`), поэтому стили одного задания не влияют на другое.
Работайте в папке `src/tasks/<задание>/start/`; условия — в комментариях `TODO` и в методичке.

| № | Задание | Папка |
| --- | --- | --- |
| 1 | CSS Modules: чиним коллизию классов | `t1-css-modules` |
| 2 | Sass: кнопка с вариантами | `t2-sass` |
| 3 | CSS-переменные: светлая и тёмная тема | `t3-css-vars` |
| 4 | styled-components: типизированная тема и варианты | `t4-styled` |
| 5 | Tailwind CSS v4: карточка утилитами | `t5-tailwind` |
| 6 | MUI: форма на готовых компонентах (бонус) | `t6-mui` |
